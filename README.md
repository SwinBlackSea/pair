# 价差哨兵（Spread Sentinel）

一个零依赖、开箱即跑的股票策略监控服务。Web 端支持策略增删改查，后端按固定间隔刷新行情并计算信号，也支持全局或单策略手动刷新。

## 功能

- 单股策略：选择股票后自动带入最新价作为基准价（可手动修改），再设置上涨/下跌阈值和触发后的买入/卖出提示。
- 价差策略：设置当前持有 A、期望持有 B；创建时自动采集两只股票的基准价，当 A 相对 B 的累计超额收益超过阈值时提示“卖 A、买 B”。
- 网格策略：设置单只股票的价格上下限与网格数量；首次行情定位档位，之后向下跨档提示买入、向上跨档提示卖出。
- 区间策略：在一条策略中设置买入下限和卖出上限；达到下限提示买入，达到上限提示卖出，持续越界时自动去重。
- 启用/暂停、编辑、软删除与回收站恢复，以及独立的触发历史与执行跟踪。
- 每次重新越过触发线生成历史快照，可标记未执行、已执行或不执行；已执行记录按触发基准价与实际执行价锁定历史收益。
- 后台默认每 10 分钟刷新启用中的策略。
- 全局刷新和单策略刷新。
- 策略首次触发时发送 Telegram Bot 通知，并对持续触发去重。
- 行情异常会记录在策略卡片上，不会中断其他策略刷新。
- 数据以 JSON 原子写入本地，无需额外数据库服务。

## 快速开始

需要 Node.js 20 或更高版本。

```bash
npm start
```

浏览器打开 <http://localhost:3000>。

服务默认使用腾讯真实行情，同时支持 A 股和港股，无需额外配置：

```bash
npm start
```

港股支持 `HK00700`、`00700.HK`、`00700`；A 股支持 `600519`、`600519.SH`、`SZ000858` 等格式。设置 `MARKET_PROVIDER=eastmoney` 时，A 股使用东方财富，港股仍会自动路由到腾讯。

> 腾讯适配器使用 `qt.gtimg.cn` 实时行情接口。它适合个人工具；生产环境或真实交易决策应使用具备正式授权和 SLA 的行情服务。

## 配置

| 环境变量 | 默认值 | 说明 |
| --- | --- | --- |
| `PORT` | `3000` | HTTP 端口 |
| `MARKET_PROVIDER` | `tencent` | `tencent`（A 股、港股）或 `eastmoney`（A 股走东财、港股自动走腾讯） |
| `REFRESH_INTERVAL_MINUTES` | `10` | 自动刷新间隔（分钟） |
| `TRADING_HOURS_ONLY` | `true` | 仅在工作日北京时间 09:30–16:30 自动刷新；设为 `false` 可改为全天刷新 |
| `DATA_FILE` | `./data/strategies.json` | 策略数据文件 |
| `TELEGRAM_BOT_TOKEN` | 空 | Telegram Bot Token；与 Chat ID 同时配置后启用通知 |
| `TELEGRAM_CHAT_ID` | 空 | Telegram 私聊、群组或频道的目标 Chat ID |

## Telegram 通知

同时设置 `TELEGRAM_BOT_TOKEN` 与 `TELEGRAM_CHAT_ID` 后启用。策略仅在从未触发状态进入 `TRIGGERED` 时通知一次；持续触发不会重复发送，恢复后再次触发会再次通知。发送失败不会中断行情刷新，并会在后续刷新时重试。Token 只应通过运行环境配置，不要写入仓库。

## 价差算法

策略创建时记录 `A₀` 与 `B₀`，刷新时取得 `Aₜ` 与 `Bₜ`：

```text
相对收益率 = ((Aₜ / A₀) / (Bₜ / B₀) - 1) × 100%
```

当相对收益率大于等于设置的阈值时触发。编辑股票代码时会自动重置基准；也可以在编辑价差策略时勾选“重新采集基准价”。

## 区间交易

区间策略将买入和卖出边界放在同一条策略中。价格小于等于买入下限时触发买入，大于等于卖出上限时触发卖出；价格持续处于同一边界之外不会重复提醒，回到区间后可再次触发。

## 网格算法

价格区间按等差方式切分：`每格价差 =（上限 − 下限）÷ 网格数量`。创建或编辑策略时只记录当前档位，不立即触发；后续刷新每跨过一条网格线生成一次买入或卖出历史。一次刷新跨越多档时合并为一条提醒，并记录跨越档数和最远参考网格价。

## API

| 方法 | 路径 | 用途 |
| --- | --- | --- |
| `GET` | `/api/strategies` | 策略列表 |
| `GET` | `/api/trigger-history` | 触发历史列表 |
| `PATCH` | `/api/trigger-history/:id` | 更新处置状态与执行信息 |
| `POST` | `/api/strategies` | 新建策略 |
| `GET` | `/api/strategies/:id` | 策略详情 |
| `PATCH` | `/api/strategies/:id` | 修改策略 |
| `DELETE` | `/api/strategies/:id` | 移至回收站（软删除） |
| `POST` | `/api/strategies/:id/restore` | 从回收站恢复策略（恢复后暂停） |
| `POST` | `/api/strategies/:id/refresh` | 刷新一条策略 |
| `POST` | `/api/refresh` | 刷新全部策略 |
| `GET` | `/api/system` | 调度与行情源状态 |
| `GET` | `/api/health` | 健康检查 |

## 项目结构

```text
public/            Web 管理界面
src/engine.js      策略计算与校验
src/market.js      腾讯/东方财富真实行情适配器
src/service.js     策略业务与调度
src/store.js       JSON 持久化
src/server.js      HTTP 服务与 API
test/              单元测试
```

本项目只生成交易提示，不会自动下单，也不构成投资建议。
